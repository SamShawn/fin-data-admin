# 用户操作手册

## 1. 登录系统
访问系统地址，输入管理员分配的账号密码。首次登录请及时修改密码。

## 2. 行情数据查询
1. 点击左侧菜单“行情数据”。
2. 支持输入“股票代码”、选择“行业”、设定“涨跌幅范围”进行组合筛选。
3. 点击表头可进行升/降序排序。
4. 向下滚动表格自动加载下一页（无需点击翻页）。
5. 点击右上角“列配置”可隐藏不关注的列。

## 3. 导出数据
点击“导出 CSV”按钮，系统将自动下载数据文件。即使数据量达到十万行，也不会占用浏览器内存。

## 4. 策略配置
1. 点击左侧“策略配置”菜单。
2. 点击“新建策略”，填写策略名称、代码。
3. 参数以 JSON 格式填写（如 `{"fastMA": 5, "slowMA": 20}`）。
