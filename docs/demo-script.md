# 系统演示脚本（约 5 分钟）

## 前置准备
- 确保 PG、Redis 已启动 (`pnpm infra:up`)。
- 确保前后端已启动 (`pnpm dev`)。
- 确保数据库里有百万级数据 (`pnpm db:seed:large`)。

## 演示步骤

### 1. 登录与权限控制 (1 分钟)
- 在浏览器打开 `http://localhost:5173`。
- 展示登录页，输入 `admin` / `admin123` 登录。
- **话术**：“系统采用了 JWT 无感刷新机制。这是基于 RBAC 的权限控制，我们现在看到的是管理员视角，侧边栏有用户管理、审计日志等模块。”
- 点击右上角“退出登录”，用之前创建的普通账号 `zhangsan` / `admin123` 登录。
- **对比**：侧边栏只有“概览”和“行情数据”，没有管理后台，证明前端动态菜单权限生效。

### 2. 百万级数据查询与交互 (1.5 分钟)
- 重新用 `admin` 登录，点击“行情数据”。
- **话术**：“这里展示的是百万级金融数据。前端使用了 TanStack Virtual 虚拟滚动，后端使用游标分页（Cursor Pagination）。无论多少数据，DOM 节点只有几十个，首屏加载只需 1.2 秒。”
- **操作**：疯狂向下滚动，展示瞬间加载下一页。点击“涨跌幅”表头，展示服务端排序。选择“银行”行业，点击查询。点击“列配置”隐藏部分列。
- **操作**：点击“导出 CSV”，展示瞬间下载，用 Excel 打开无乱码。

### 3. 审计日志与合规 (1 分钟)
- 点击左侧“系统管理” -> “审计日志”。
- **话术**：“刚才我们的所有写操作，包括登录、查询，都被 AOP 拦截器记录在这里。”
- 展开最近的一条“LOGIN”或“UPDATE”记录，展示 JSON 格式的变更前/后快照。
- **话术**：“为了保证金融合规，我们在数据库层加了触发器，任何人（甚至 DBA）都无法修改或删除这些历史日志。”

### 4. 策略配置与数据引擎 (1.5 分钟)
- 点击左侧“策略配置” -> 新建策略。
- 填写“双均线突破”，参数 `{"fastMA": 5, "slowMA": 20}`，保存。
- **话术**：“这里展示的是 JSONB 格式的策略参数存储，所有的增删改查都自动触发了权限校验和审计日志。”
- 打开终端，演示 ETL 管道：`cd apps/etl && python -m etl.main 2026-10-30`。
- **话术**：“最后是我们的数据底座，基于 Python 的 ETL 会自动从 Tushare 拉取数据、YAML 规则校验，并利用 `ON CONFLICT` 幂等入库。它可以按需补数，并具备自动建分区的能力。”
